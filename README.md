# exam-3
# Описание проекта: 
Веб-сайт IT-компании (Software Development Company)
Тип проекта: Многостраничный корпоративный веб-сайт / Лендинг для технологической компании.
Визуальный стиль: Современный минимализм, темная тема (Dark Mode) с неоновыми синими, фиолетовыми и зелеными акцентами. Использование качественной 3D-графики и структурированных карточек для отображения информации.

# Основные разделы сайта
Home (Главная страница):

Первый экран: Эффектный заголовок «Transforming Data into Decisions», краткое описание деятельности компании, кнопки призыва к действию (CTA) и футуристичный 3D-элемент.

Блок доверия: Слайдер или сетка с логотипами известных компаний-партнеров (Zapier, Spotify, Zoom, Slack, Amazon, Adobe).

Преимущества / Ключевые направления: Информационные карточки с иконками, раскрывающие главные компетенции команды (Predictive Analytics, AI Consulting, Data Engineering).

FAQ: Раздел часто задаваемых вопросов в виде интерактивного аккордеона.

# Services (Услуги):

Обзор решений: Секция «Our Comprehensive Digital Solutions», объясняющая комплексный подход компании к разработке.

Сетка услуг: Детальные карточки по ключевым технологическим направлениям: Machine Learning Solutions, Blockchain Development, Algorithmic Trading, Data Engineering, Predictive Analytics. Каждая карточка содержит краткое описание, теги технологий и кнопку перехода.

# Career (Карьера):

Мотивационный блок: Секция «Build the Future with Us» для привлечения ИТ-специалистов.

Фильтр вакансий: Панель сортировки предложений по категориям.

Открытые вакансии: Список доступных позиций (Web Designer, Mobile App Developer, Digital Marketing Specialist, Project Manager) в виде карточек с указанием вилки зарплаты, требуемого опыта и дедлайна для подачи заявки.

# Career Details (Детали вакансии):

Подробное описание: Внутренняя страница конкретной позиции (на примере Web Designer) с разделами: обязанности (Responsibilities), требования (Requirements) и условия работы (Benefits).

Форма отклика: Встроенная форма для отправки резюме соискателя прямо на сайте.

Похожие вакансии: Блок рекомендаций с другими актуальными предложениями компании.
